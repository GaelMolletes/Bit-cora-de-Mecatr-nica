    Sesión número 1 de Mecatrónica

    Para empezar, el profesor nos pregunto acerca de como iba nuestra primera semana, si ya estabamos pensando en cambiar de carrera o darnos de baja, jaja. Luego, el profesor nos explico y aconsejoj que vayamos de una vez consigueind nuestro credito/ evidencia de un taller artístico o un evento artístico, para de una vez ir preparandonos para tener nuestro ASE. Posteriormente, podría decirse que ahora si inició la clase de verdad.

    GitHub

    Comenzo exlicandonos que las "tareas" que estaríamos ahciendo durante le periodo, sería una bitácora de las clases. Pero más que una simple bitcaora en Word o google docs, lo haríamos por medio de una página web, por lo que nos hizo a todo meternos a GitHub.

    GitHub es una plataforma en la nube, muy util para almazenar, gestionar o colaborar en proyectos. Muy útil, pues ouedes acceder de mamnera gratuita al codigo y programas de otros usuarios. La verdad, yo solo la había utilizado para descargar Drivers de controles o programas para juegos.

    El profesor nos hizo crear una cuenta en Github, y nos hizo copiar el repositorio que tenía el, pues es una plantilla practicammente ya hecha de la página web. Ahora solo faltaba el como poder editar en si la página web.

    Git

    No entendi bien bien lo que es git, pero por lo que pude encontrar en internet, es una herramienta que registra todos los cambios se hacen en los archivos de un proyceto, como el código, docummentos, imágenes, etc.

    Al tener Git instalado, se permite poder usarlo desde VisualCode, una aplicación para poder programar de manera comoda y sencilla.

    Visual Code

    Por ultimo, instalamos Visual code, que como memncione antes, permite programar mas facilemtne. Desde ahí, el profesor nos explico como funcionaba todo. Para empezar, debias clonas la carpeta que tenías en GitHUb en tu PC, y que estarías modificando dicho archivo para que los cambios se reflejaran en tu pagina web. Despúes, desde visual Studio utilizas comandos para poder clonar esa mismma carpeta, y ya tener todos los archivos disponibles para programar.

    El profesor, al ya tener todo el setup hecho y explicado, nos enseño a colocar imágenes, cambiar las letras, (como poner títulos, subtítulos, negritas y así.) y por último, nos enseño como agregar "entradas" a la bitácora con el tipo de archivo MC
